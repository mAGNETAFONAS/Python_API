# Python-API

Python-API is a small web application that provides an API for 
accessing files and database data stored locally on the server.

## Installation
All required packages are named in the requirements.txt file
```bash
pip install -r /path/to/requirements.txt
```
## Usage
Using scripts in the Docker_scripts directory or standalone command, start docker compile file

```bash
./Docker_Scripts/start.sh
```
Once images are built and containers are running you can connect to the program with
localhost:8000.
